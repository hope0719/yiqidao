# 技术说明与复现

日期：2026-10-13。对应 Sites 公网网站，不把其他部署路线的状态混入本说明。

## 调用链

用户确认表单 → 网站服务端验证和调用规模预估 → 百炼 Managed Agent 会话 → yiqidao Skill → Python 引擎 / FlyAI 官方 CLI → 原生 JSON → 网站来源校验、字段筛选 → 城市比较 / 详情 / 方案快照。

已验收配置为 Qwen3.8-Flash、Agent v4、云端 Skill 1.3。模型执行工具调用；交通组合、金额、停留窗口由引擎计算。自然语言辅助填表是本地规则，与该调用链分开。

网站代码入口：`sites/yiqidao/app/api/[...path]/route.ts`、`sites/yiqidao/lib/travel.ts`。引擎入口：`yiqidao/scripts/yiqidao.py`；云端部署须具备 Skill 文件和 Python/bash 工具，不能只复制网站就视为完整复现。

## 配置

网站需 Node >=22.13.0，并有 Cloudflare Workers / D1 运行环境。使用现有项目的依赖锁文件安装、按 `drizzle/` 迁移初始化数据库，并设置原生绑定；不能用纯静态服务器替代 API。

服务端配置项：

| 项 | 用途 |
|---|---|
| BAILIAN_API_KEY | 百炼秘密凭证 |
| BAILIAN_HOST | 该账号北京地域 Managed Agent 专属域名，不含协议 |
| BAILIAN_AGENT_ID | 已部署并挂载 yiqidao Skill 的智能体 ID |
| BAILIAN_ENVIRONMENT_ID | 可选；不填使用默认环境 |
| FLYAI_API_KEY | 正式旅行接口凭证，秘密配置并按会话注入；默认 CLI 配置是否可用由上游决定 |
| BAILIAN_ENABLE_LIVE | 配置和验证完成后设为 1 |
| MAX_CALLS_PER_JOB | 网站单任务旅行调用上限，当前默认 20 |

不在此材料中提供密钥值。FlyAI 官方 CLI 已验收版本 1.0.16。安装或云端配置变化后须重新验证，模型名与 Skill 版本也不能凭本说明推定未来平台状态。

## 验证方式

网站：在 `sites/yiqidao/` 执行 `node scripts/check-travel.mjs` 与 `npx tsc --noEmit`。构建可执行 `npm run build`；现有 Sites 部署按平台项目绑定发布，不能把生成文件误当独立静态网站。`npm start -- --port 8787` 为构建后的本地 Workers 预览，需先准备 D1 与环境配置。

引擎：按 README 草稿运行离线测试和 fixture 命令，不消耗真实接口。真实复现需要自己的百炼与 FlyAI 凭证、挂载 Skill 和可用额度；日期变化后必须更新请求，不要求重复得到历史车次。

- 酒店整房报价、容量、库存和其他支出未确认，全程预算未知；不自动预订或支付。
- 当前真实任务全站最多 6 个/滚动24小时、单访问身份最多3个/24小时、全站1个活动任务。匿名 cookie 不能可靠限制同一真实用户，任务限额也不等于 token 或金额硬预算。
