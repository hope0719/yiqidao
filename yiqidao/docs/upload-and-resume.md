# 上传与续接

## 新建智能体后

1. 创建支持 Python/bash 与文件读写的智能体。先上传 `yiqidao-skill-v0.4.2.zip`。如果平台“技能”入口要求 Skill 包，用这个包；如果只能上传普通文件，上传后要求解压读取 `yiqidao/SKILL.md`，不要假设普通文件自动成为已启用技能。
2. 配置官方 FlyAI CLI 和凭证，凭证通过密钥管理/环境配置；先不发布部署。
3. 把以下启动提示词发给智能体，让它先自检，输出成功证据后再做真实查询。
