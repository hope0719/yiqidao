# 本地修复记录 · 2026-10-11

恢复来源：yiqidao-skill-v0.1.0-20261010.zip。原始包完整保留。首次恢复版本0.2.0，当前修复版本0.4.1。

## 修复

- 原包没有 SKILL.md/README，补齐技能入口、运行说明、启动提示词与续接说明。
- fixture 缺文件时不再回落真实请求；缓存保留原查询时间，实时默认 15 分钟有效期，不缓存任何失败响应。
- 原本每条查询可经历多次风控等待，默认451/429/401立即停止本轮后续真实请求；新增总时限和调用次数限制，超时尝试也计数。
- 开始规划前写请求检查点，默认保存完整状态；新增 --resume-state 和 --output。JSON 输出补齐交通、酒店、成员费用、城市方案和来源。
- 服务失败导致无法出方案时返回 error，不能误判为旅行条件无解；不完整搜索明确标注。不可用交通方案不再额外查询酒店，不可行城市不再查询景点。
- 修复本地成员漏算住宿、部分票价缺失被误标费用完整、已知团队费用超预算但有缺失时不阻塞等问题。
- 酒店选择改为价格优先，同价看评分，避免评分优先排除可行预算；移除按预算45%过滤酒店的隐藏启发式限制。
- 加入异常响应结构检查、损坏缓存处理、缓存原子写入、无效输入提示。交通时长缺失时优先用实际时刻差推导，负值/非有限价格不参与费用计算。
- 提供明确标注的虚构离线样例；原先跳过的端到端回放测试现在能够实际运行。

## 验证边界

单元测试和离线端到端回放只证明本地计算及模拟接口行为，不证明真实 API、报价、库存或部署可用。无真实凭证参与本次验证，没有大赛提交或发布部署。

当前仍只搜索首个日期对和有限班次，以城市排序和有限策略为主，不保证穷尽所有往返组合。界面由宿主智能体提供。真实验收按 docs/upload-and-resume.md 执行。

## 0.3.0 · 真实测试后修复

- 搜索展示价与整房报价分离。任意搜索价格都不进入住宿分摊；支持用户明确确认的hotel_quote并校验日期、人数和价格，未确认时状态needs_confirmation/退出码5。
- 青旅/床位类不再因低展示价自动成为预算最优酒店；优先展示普通候选供用户核实，排名不依赖未经确认的房价。
- 校验每间房人数、未知成员、整数房间/晚数、短途晚数范围。
- 默认共同停留扣除60/90分钟缓冲，跨日到达提示夜间入住。
- 过滤路线不匹配、无效时刻和不可能的中转；接口返回无法使用的条目记为解析失败，不假称无班次。
- 缓存有效期按原查询时间核验，复制旧缓存不能伪装新数据；请求和状态采用原子写入。
- 混合飞机/火车真实查询通过，详细证据见live-acceptance.md。

- 修复时长上限的错误矛盾判断：往返上限小于单程上限仍可能由短程班次同时满足。显式空交通方式不再被替换成默认两种。
