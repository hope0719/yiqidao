# 一起到 · Sites 网站

运行于 Vinext / Cloudflare Workers，D1 保存任务及方案快照。沿用原网页视觉，补齐表单、任务进度、动态城市比较、详情、保存、匿名分享、PNG导出。web/为早期静态原型，本目录为网站部署源。

## 当前能力

- 演示通过服务端生成虚构结果，全程标明mock，不发起旅行或模型调用。
- 真实入口连接既有Managed Agent v4与yiqidao@1.3。是否启用以服务端health结果为准；线上验证摘要见仓库根目录提交材料/03-技术说明与复现.md。
- 自然语言框使用本地规则识别城市与预算，不声称模型解析。交通仅支持选择飞机/火车，其他精细要求暂不展示。
- 任务刷新恢复；保存记录按当前访问身份隔离；分享称呼为成员1等，仍包含出发城市、日期和交通信息。
- 快照访问有效期7天，当前未配置后台定期物理删除，不承诺到期即删除存储。

## 真实查询配置

在Sites原生环境变量管理中设置BAILIAN_API_KEY、BAILIAN_HOST、BAILIAN_AGENT_ID，验收后开启BAILIAN_ENABLE_LIVE=1。BAILIAN_ENVIRONMENT_ID可选，不填使用平台默认环境；FLYAI_API_KEY可选，不填使用官方CLI默认配置，不能从历史测试会话复制凭证。凭证不得写入源代码、网页或公开包。当前适配仅接受北京地域的百炼Managed Agent域名。

真实调用最多20次/任务、全站6个任务/24小时、单访问身份3个任务/24小时，全站最多1个活动任务。匿名cookie不构成可靠的实名额度；全站限额仍生效。停滞任务需维护者核对，网站不会自动重发或批准工具。
